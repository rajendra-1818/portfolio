# Sri Rajendra — Portfolio Projects

Three self-contained demo projects demonstrating backend engineering, Python document retrieval, and frontend systems thinking. Each folder can be run independently after installing its prerequisites.

## Projects

| Project | Focus | Stack |
| --- | --- | --- |
| [Orderflow API](./orderflow-api) | Stateful order workflow and REST API design | Java 21, Spring Boot, Validation, JUnit, Docker |
| [DocuFlow AI](./docuflow-ai) | Explainable document retrieval service | Python, FastAPI, SQLite, scikit-learn, pytest |
| [OpsBoard](./opsboard-react) | Production reliability dashboard prototype | React, TypeScript, Vite, CSS |

Each project includes a README, runnable commands, and a description of implemented behavior and limitations. The repository's GitHub Actions workflow checks Java tests, Python tests, and the React production build. These are portfolio demos, not production deployments.
